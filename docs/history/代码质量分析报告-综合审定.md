## 三、代码审查中新发现的问题（两份报告未提及）

> 以下是在逐文件阅读代码、验证报告建议时发现的新问题。

### 3.1 🔴 Bug / 安全风险

#### N1. `aly-client DeleteProject` 未过滤已软删除项目

**位置**：`server/internal/service/project_service.go` L201-208

```go
func DeleteProject(ctx context.Context, projectName string) models.CommonResponse {
    _, err := db.Client.Project.Update().Where(project.NameEQ(projectName)).
        SetIsDeleted(true).Save(ctx)
```

**问题**：与 `UpdateProject`（L80）和 `SetForceUpdate`（L111）相比，`DeleteProject` **缺少 `IsDeletedEQ(false)` 过滤**。这意味着：
1. 可以对一个已经删除的项目"再次删除"——虽然幂等，但违反了一致性约定
2. 未检查 `affected == 0`——如果删除不存在的项目，仍返回 OK（与 `SetForceUpdate` L117 不一致）

**修复**：
```go
func DeleteProject(ctx context.Context, projectName string) models.CommonResponse {
    affected, err := db.Client.Project.Update().
        Where(project.NameEQ(projectName), project.IsDeletedEQ(false)).
        SetIsDeleted(true).Save(ctx)
    if err != nil { return models.NGWithError(err) }
    if affected == 0 { return models.NG("项目不存在: " + projectName) }
    return models.OK()
}
```

**优先级**：� 高（与其他函数行为不一致）

---

#### N2. `AlyUpdateClient.MainLoop` 三路 `.Result` 调用（比构造函数更危险）

**位置**：`client/aly-client-sdk/AlyClient.CSharpSDK/AlyClient.CSharpSDK/AlyUpdateClient.cs` L86、L110、L113

```csharp
var status = AlyApi.CheckUpdateAsync(UpdatorExePath).Result;   // L86
var downloadResult = AlyApi.DownloadUpdateAsync(...).Result;  // L113
// L110: AlyApi.CheckUpdateAsync(...).Result
```

**问题**：原报告仅提到构造函数 L54 的 `.Result` 风险。实际上 **MainLoop 线程（由 Task.Factory.StartNew 启动）内部也调用了 3 次 `.Result`**。如果 `aly-client.exe` 内部异常挂起（不退出也不返回），每次 `.Result` 都会阻塞 5 秒轮询周期。

**修复**：将 MainLoop 重构为 async 方法并使用 `await`。若受限于 .NET 4.0，用 `ContinueWith` + `ConfigureAwait(false)` 避免同步阻塞。

**优先级**：� 高

#### N3. `aly-client DownloadUpdateAsync` 变量名严重误导

**位置**：`client/aly-client-sdk/AlyClient.CSharpSDK/AlyClient.CSharpSDK/AlyApi.cs` L56

```csharp
var stdoutTask = process.StandardOutput.ReadLine(); // 返回 string 不是 Task！
```

#### N6. `aly-client Process.HasExited` 后不必要 `WaitForExit(30000)`

**位置**：`client/aly-client-sdk/AlyClient.CSharpSDK/AlyClient.CSharpSDK/AlyApi.cs` L157-160
